# ml-baseball-analytics

The main files of interest are:
- `ML2_Project_Report.pdf`
- `nick/ML2_Project.Rmd`
Analysis of historical baseball data using machine learning. We applied LightGBM and Elastic Net Regression to Fan Graphs baseball data to predict the batting average of players in their next season given the Fan Graphs standard and advanced statistics from the current season. Additionally, we examined eXplainable AI (XAI) techniques such as SHAP and PDP. Note this repo is a bit messy.
